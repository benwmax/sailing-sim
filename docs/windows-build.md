# Building on Windows (notes, untested)

The game has only been built and measured on the Mac. Nothing in it is Mac-only: the physics in `Source/SailingPhysics`
is standard C++, the rendering uses no Metal-specific features, and content is generated by Python inside the editor.
These are the steps that should work on Windows; they have not been run.

1. Install Unreal Engine 5.8.3 from the Epic Games Launcher and Visual Studio 2022 (17.8 or later) with the
   "Game development with C++" workload and a Windows 10/11 SDK. Install Git LFS and run `git lfs pull` after cloning.
2. Generate project files: right-click `SailingSim.uproject` > Generate Visual Studio project files, or
   `"<UE>\Engine\Build\BatchFiles\Build.bat" -projectfiles -project="<repo>\SailingSim.uproject" -game -engine`.
3. Build the editor: `"<UE>\Engine\Build\BatchFiles\Build.bat" SailingSimEditor Win64 Development "<repo>\SailingSim.uproject" -waitmutex`.
4. Tests: `"<UE>\Engine\Binaries\Win64\UnrealEditor-Cmd.exe" "<repo>\SailingSim.uproject" -nullrhi -unattended
   -ExecCmds="Automation RunTests SailingSim;Quit" -ReportExportPath="<repo>\Artifacts\TestReport"`.
5. Package: `"<UE>\Engine\Build\BatchFiles\RunUAT.bat" BuildCookRun -project="<repo>\SailingSim.uproject" -platform=Win64
   -clientconfig=Development -build -cook -stage -pak -iostore -package -archive -archivedirectory="<repo>\Packaged"`.
   The terrain bakes in `Content/TerrainData` are staged by `DefaultGame.ini`, as on the Mac.

What to expect:

- The `scripts/*.sh` helpers are bash and Mac-specific (they use `open` and the macOS app container); run them under
  Git Bash only for `polar.sh` and `traffic.sh`, which need a clang or g++ on the path.
- `Saved/` (logbook, photos, bench output) is next to the executable in a packaged build, not in a container.
- Warnings are errors on the Mac's clang; MSVC may raise different ones (for example implicit double-to-float
  conversions, C4244). Fix them in place rather than turning the setting off.
- Frame rates have only been measured on an M5 Pro; the quality tiers are set for it.
