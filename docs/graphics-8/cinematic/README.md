# Cinematic look (graphics-8/cinematic)

Bean's reference is two Ship Simulator-style frames: a low sun facing the camera with heavy bloom and glare, a warm
orange-to-blue grade, dense sun glitter across a choppy sea, and haze veiling the far shore. The look is "cinematic
photo", not the game's neutral metered look. This pass adds a **Cinematic** look on Medium and above, chosen with
Settings > Graphics > Look (Natural or Cinematic). Photo mode always uses it.

## How it decides

`UsesCinematicLook` (`VisualPipeline.h`):
- `-SailingCinematic=0|1` decides when it is given.
- Otherwise the look is on if the Settings toggle is on, or the game is in photo mode.
- It's never on for Low.
- Capture mode stays natural unless `-SailingCinematic=1` is passed, because its stills are compared with real
  photographs.

`ASailingEnvironment` re-reads the decision with each sun update. `AWaterSurface` reads it for the glitter.

## Pieces

| Piece | Medium | High | Ultra | Where |
|---|---|---|---|---|
| Colour grade LUT | yes | yes | yes | `Tools/look/make_grade_lut.py` -> `Inputs/look/T_CinematicLUT.png` -> `/Game/Look` (`scripts/import_look.py`) |
| Tone curve: slope 0.92, toe 0.58, shoulder 0.24 (engine 0.88, 0.55, 0.26) | yes | yes | yes | `ApplyCinematicLook` |
| Vignette 0.45, film grain 0.06 | yes | yes | yes | `ApplyCinematicLook` |
| Bloom: Gaussian, size scale 6 (engine 4), intensity 0.6 | yes | yes | | `ApplyCinematicLook` |
| Bloom: FFT convolution, intensity 0.5, generated kernel | | | yes | `Tools/look/make_bloom_kernel.py` -> `T_BloomKernel` |
| Lens flare 0.12, bokeh 1.2 | | | yes | `ApplyCinematicLook` |
| Sun glitter: the unresolved roughness floor cut by 40% | | yes | yes | `M_WaterV4` `Glitter`, `AWaterSurface` |
| Haze glowing toward a sun under 25 deg | yes | yes | yes | the analytic fog's directional inscattering, `UpdateFog` |

The grade LUT:
- Warm highlights, cool shadows.
- Lifted blacks: a black input comes out as (2, 8, 14), cool; white as (255, 255, 246), warm.
- A gentle S-curve.
- Saturation a little lower in the shadows and a little higher in the midtones.

Under a storm deck the grade's intensity falls to 0.4: gloom is grey, not teal and amber.

The bloom kernel:
- A core, a 1/r^2 glare skirt, a faint six-pointed star and a faint horizontal (anamorphic) streak.
- The engine normalises the kernel's energy, so each term's share is what counts.
- With the first weights the skirt carried 70% of the energy and the Ultra frame washed out. Now the core keeps 84%.

**Nothing here moves a light.** The sun keeps Perf 2's stepped direction (#71, #72): everything is a post-process
setting, a fog constant or a material scalar. The natural look keeps the fog's own directional-inscattering values
(saved at the first update and restored).
