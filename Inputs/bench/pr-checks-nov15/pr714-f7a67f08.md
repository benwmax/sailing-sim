## Cause and fix

The new test file `Source/SailingSimTests/Private/UiOverhaulTests.cpp` is in the SailingSimTests module. It uses `SailUI::`
functions and colour tokens that are defined in the SailingSim module and declared in
`Source/SailingSim/Public/UI/SailUIStyle.h` without `SAILINGSIM_API`.
- On the Mac, symbols are visible across modules by default, so it links there.
- On Windows, a DLL exports only what is marked, so the test module can't find them. That gives 15 LNK2019/LNK2001
  errors and no warnings.

Add `SAILINGSIM_API` to the declarations the tests use (at f7a67f08):
- line 22: `extern SAILINGSIM_API const FLinearColor Ink, Panel, PanelSolid, Raise, Line, Fg, Muted, Dim, Accent, AccentInk, ...;`
  (the specifier covers every name in that declaration);
- line 25: `extern SAILINGSIM_API const FLinearColor Paper, PaperInk, PaperMuted, PaperLine, AccentDeep, Brass, Caution;`;
- line 33: `SAILINGSIM_API FSlateFontInfo Font(EType Type);`;
- line 36: `SAILINGSIM_API bool IsUpper(EType Type);`;
- line 37: `SAILINGSIM_API FText Txt(const FString& S, EType Type);`;
- line 62: `SAILINGSIM_API const TCHAR* UiModeName(EUiMode Mode);`.

The definitions in the .cpp need no change. This is the same rule as the MSVC portability note in CLAUDE.md: what a test
module uses from SailingSim must be exported.
