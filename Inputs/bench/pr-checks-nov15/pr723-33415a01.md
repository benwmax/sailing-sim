## The failing test: SailingSim.UI.SessionFlow

Verbatim:
`Source\SailingSimTests\Private\UITests.cpp(153): Expected 'No span: the shortest, no length' to be "0.1 nm", but it was "5 nm".`

The test is right, and the bug is in the code. It is not specific to Windows: the Mac gives the same result.

`SSailHud::MiniMapScaleBar` (`Source/SailingSim/Private/UI/SailHud.cpp:987` at 33415a01) computes
`PxPerM = SpanM > 0 ? WidthPx / SpanM : 0` and then picks the first length whose bar fits in 40% of the width. With
`SpanM == 0`, `PxPerM` is 0, so every bar is 0 px. The first length, 5 nm, "fits", and it returns "5 nm" with a 0 px
bar instead of the shortest.

Fix: return the shortest straight away when there is no span, before the loop. For example:
`if (PxPerM <= 0.0) { OutBarPx = 0.f; return Names[UE_ARRAY_COUNT(Names) - 1]; }`
The other four checks in that block pass:
- 3 km gives 0.5 nm;
- the bar for it is 926 m long;
- 8 km gives 1 nm;
- that bar is inside 40% of the width.
