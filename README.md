# SailingSim

A technically accurate sailing simulator built in Unreal Engine 5.8. First boat: J/22. First world: Lake Ray Roberts, Texas.

The research and phased plan live in the Claude Doc "Sailing Game: Research and Phased Plan". This repo is Phase 0: the project, the build-and-test loop, and a placeholder boat floating on flat water.

## Layout

| Path | What it is |
| --- | --- |
| `SailingSim.uproject` | C++ project, Blank template, no starter content. Plugins: Enhanced Input, Water, Python (editor only) |
| `Source/SailingPhysics` | Boat physics. Depends on Core only (no Engine, no rendering). Fixed 120 Hz stepper and the Phase 0 hydrostatics stub |
| `Source/SailingSim` | Game module: `ASailboatPawn` (placeholder J/22, input, chase camera), `AFlatWater`, `ASailingGameMode` |
| `Source/SailingSimTests` | Automation tests (editor only) |
| `Content/Maps/Lake.umap`, `Content/Materials` | Generated by `scripts/make_lake_map.py` and `scripts/make_materials.py` |
| `scripts/` | Build, test, map, package and benchmark scripts |
| `Build/` | Unreal's per-platform build folder (generated, ignored). Packaged apps go to `Packaged/`, never here |

## Build, test, package

```sh
scripts/build.sh          # UnrealBuildTool, SailingSimEditor Mac Development
scripts/test.sh           # automation tests headless; report in Artifacts/TestReport
scripts/make-content.sh   # regenerate the materials and Content/Maps/Lake.umap from scripts/*.py
scripts/package-mac.sh    # RunUAT BuildCookRun to Packaged/Mac/SailingSim.app
scripts/bench-mac.sh 20   # run the packaged app for 20 s, print fps, save a screenshot
```

## Controls

Press **?** (controller: View) in the game for the controls card and **Tab** (controller: Menu) for settings.
Keys are rebindable: see `USailingInputSettings` in `Source/SailingSim/Public/SailingSettings.h`.

| Action | Keyboard and mouse | Controller |
| --- | --- | --- |
| Tiller (bow left / right) | A / D or Left / Right | Left stick |
| Mainsheet trim / ease | W / S | Right / left trigger |
| Jib sheet trim / ease | E / Q | Right / left bumper |
| Crew hike out / in | F / V | D-pad up / down |
| Wing-on-wing | G | X |
| Full layout only: traveler, vang, cunningham, outhaul, backstay | Z / C, 1-2, 3-4, 5-6, 7-8 | D-pad left / right, A / B |
| Learning mode, difficulty, instruments, reset | L, K, H, R | Y |
| Settings menu, controls card | Tab, ? | Menu, View |
| Orbit / zoom camera | Mouse, wheel | Right stick |

**Simple** layout (the default, and always on Easy): you steer, trim both sheets and hike; the crew handles the
traveler and sail shape. **Full** gives you every control. **Trim assist** (its own setting) lets the crew trim the
sheets whenever you leave them alone for 4 seconds. Learning mode shows the wind diagram, point of sail, trim and
weather tips; game mode hides them. The physics is the same in every combination.

## Weather and time

In the settings menu (Tab): **Weather** (calm morning, afternoon breeze, overcast, rain, thunderstorm, random day),
**Start time** (06:00 to 20:00, local solar time at Lake Ray Roberts), **Weather seed** (same seed, same gusts,
shifts and lightning), **Graphics quality** (Low / Medium / High) and **Volume**. The thunderstorm plays in about nine
minutes: towering cells build to the west-northwest, the gust front crosses the water (watch for the dark band and
whitecaps) with a sharp shift and gusts near 30 knots, rain follows a minute later with lightning and thunder at the
speed of sound, then it clears to a light northwesterly.
